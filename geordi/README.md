# Geordi v0.4.0

Independent, preliminary Home Assistant Marketplace extension scanner. Includes an admin-only sidebar dashboard, manual scans, **automatic polling and update scans**, persistent scan queue, version comparisons, and Home Assistant notifications.

Marketplace release ZIPs and card assets are selected when available, and Semgrep runs only in an offline namespace. Exact parity against installed local files and full Barkley feature parity are still unavailable; incomplete checks stay visible. The app has not been tested on live HA OS and is not a replacement for security review.

See the **Documentation** tab for configuration, permissions and safety limitations.
